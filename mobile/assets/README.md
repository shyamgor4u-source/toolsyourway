# App assets

These PNGs are **solid-indigo placeholders** (brand color `#1E1650`) so the app
builds and runs. Replace them with real branded artwork before a Play Store
release:

- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `splash.png` — splash screen image (centered logo on `#1E1650`)
- `favicon.png` — web favicon

See the store assets checklist in `../README.md`.
