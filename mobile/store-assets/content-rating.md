# Content Rating — Google Play questionnaire notes

Play assigns a rating from the IARC questionnaire you complete in the Console.
ToolsYourWay is a **business/productivity** app with no game, gambling, or mature
content. Expected outcome: **Everyone / PEGI 3 / rated for general audiences.**

## Questionnaire guidance (answer truthfully in the Console)

| Topic | Answer | Why |
| --- | --- | --- |
| App category | Utility, Productivity, Communication, or Other (not a game) | It is a business tool |
| Violence | No | None |
| Sexual / nudity content | No | None |
| Profanity / crude humor | No | None |
| Controlled substances (drugs/alcohol/tobacco) | No | None |
| Gambling (simulated or real) | No | None |
| User-generated content shared with others | **Yes** | Users create/brief content the app helps publish to their own social channels |
| Users can interact / share content | **Yes** | Content can be published to connected social accounts |
| Shares user location | No | App does not collect location |
| Digital purchases | **No (in-app)** | No in-app billing in v1.0.0; purchases happen on the web |

## Notes
- Because the app helps users **publish content to social platforms**, answer
  "users can interact or share content" honestly — this does not raise the rating
  for a business app but may add an interactivity descriptor.
- If a future release adds in-app purchases (Play Billing), update the "digital
  purchases" answer and re-take the questionnaire.
- Re-take the questionnaire whenever the feature set materially changes; an
  inaccurate rating can get the listing removed.
